# 📌 Overview of Uber Rides Data Analysis Project

# Objective:

Analyze Uber rides data to derive insights about ride frequency, trends, and patterns over time.

# Dataset:

The data appears to cover Uber rides in New York City.

Includes features such as date/time, latitude, longitude, and base.

# Libraries Used:

pandas, numpy – Data manipulation.

matplotlib, seaborn – Data visualization.

calendar, datetime – Time-based operations.

# Data Preprocessing:

Converted Date/Time column to datetime format.

Extracted new time-related features: hour, day, weekday, month.

Exploratory Data Analysis (EDA):

# Frequency plots by:

Hour of the day

Day of the month

Weekday

Used bar plots and line plots to visualize temporal trends.

# Heatmaps:

Created heatmaps to show ride density by:

Hour vs Weekday

# Geospatial Analysis:

Scatter plots of pickup locations using latitude and longitude.

Color-coded by base and ride density.

# Base Analysis:

Count and visualize number of rides per Uber base.

Compared ride frequency across different bases.

# Monthly Trends:

Plots showing how rides varied by base over months.

Observed patterns for seasonality or peak times.

# Conclusion:

The analysis highlights rush hours, popular days, and key areas of Uber usage.

Helps in understanding user behavior and optimizing operations.
